# Russian Ark novella

A prose adaptation of *Russian Ark*, organized into 29 dated sections. Each section includes the prose version and a corresponding literary quotation version. All source references are collected after the final quotation section.

[Download the Word document](Russian_Ark_Story_with_Literary_Quotations.docx)

The quotation version contains 799 passages, including 677 by Russian authors. Quotations follow each scene’s implied century; contemporary and undated scenes use twentieth-century literature. They provide thematic parallels to the prose rather than literal retellings of every detail.

The references retain the bracketed citation style, italic titles and hanging indents used in *What Takes Hold*. Numbers identify distinct quoted passages and run consecutively across all sections in order of first appearance. Different passages from the same book receive separate numbers; an exact repeat from the same source location reuses its number. The 799 citation occurrences link to 677 distinct passage references, numbered [1]–[677], with 122 repeat occurrences. Every reference appears at the end and includes complete source details and the passage location; citation tooltips also give the locations.

The historical dates, original prose and quotation wording are preserved. All 799 passages have been checked for wording, century assignments and citation numbering. All citation targets and passage locations have been verified, with no numbering gaps or broken citation links, and all 63 rendered pages have been reviewed.
