# Russian Ark novella

A prose adaptation of *Russian Ark* and a corresponding literary quotation version, each organized into 29 dated sections.

Two Word editions are available:

- [Sourced version followed by references and prose](Russian_Ark_Sourced_Version_References_and_Prose.docx): the current edition contains the complete sourced literary version, followed by all references, then the complete prose version. Dates appear in parentheses in the chapter headings of both versions. The latest pass replaced eight quotations to improve the fit of actions and images: careful footing, listening, accepting an invitation to look, dancing, uncertainty, empty frames, a throne, and quiet speech. All 60 rendered pages have been reviewed.
- [Versions paired within each section](Russian_Ark_Story_with_Literary_Quotations.docx): an earlier edition in which each prose section is followed by its quotation version, with references collected at the end. This edition retains its earlier quotation choices and 677 distinct references. All 63 rendered pages were reviewed when it was produced.

The current quotation version contains 799 passages, including 669 by Russian authors. Quotations follow each scene’s implied century; contemporary and undated scenes use twentieth-century literature. They provide thematic parallels to the prose. Excerpts are retained without added ellipsis markers; punctuation belonging to the original authors remains.

The references retain the bracketed citation style, italic titles and hanging indents used in *What Takes Hold*. Numbers identify distinct quoted passages and run consecutively across all sections in order of first appearance. Different passages from the same book receive separate numbers; an exact repeat from the same source location reuses its number. In the current edition, 799 citation occurrences link to 692 distinct passage references, numbered [1]–[692], with 107 repeat occurrences. Every reference appears after the complete sourced literary version and includes source details and the passage location; citation tooltips also give the locations.

The historical dates, chapter order, paragraph groups and original prose are preserved. All eight new replacement quotations have been checked verbatim against the source texts, their printed locations and the required centuries. Citation numbering and targets have been verified, with no numbering gaps or broken citation links.
